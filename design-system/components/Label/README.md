# Label

Etiqueta rellena en mayúsculas que abre una sección o un panel.

## Cuándo usarlo
- Sobre el título de una sección o dentro de un panel de vidrio, para nombrar de qué trata. Una por bloque.

## Markup
```html
<span class="label">Nuestras soluciones</span>
```

## Reglas
- Fondo `--tint`, texto blanco (`--paper`), 11 px, 500, espaciado 0,08 em. Nunca con contorno ni como texto suelto.
