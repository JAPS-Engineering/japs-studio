# PillLink

Píldora de contorno para la acción secundaria junto a la CTA («Cómo funciona», «Ver portafolio»).

## Cuándo usarlo
- Al lado de una `Cta` en el hero o una sección, nunca sola como acción principal.
- Alto 52 (56 en móvil); en `ctas` se alinea con la CTA grande.

## Markup
```html
<div class="ctas"><a class="pill-s" href="/#como-trabajamos">Cómo funciona</a><a class="cta cta--lg" href="/contacto">…</a></div>
```

## Reglas
- Borde interior `--hairline-strong`, texto `--text`, hover `--hover`.
