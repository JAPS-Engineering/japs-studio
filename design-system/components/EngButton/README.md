# EngButton

Píldora de contorno con un círculo claro al final, para salir a japs.ing («Conócenos»).

## Cuándo usarlo
- Para enlaces que llevan a JAPS Engineering. Se distingue de la `Cta` porque no usa el agua: el agua es de Studio.

## Markup
```html
<a class="engbtn" href="https://japs.ing/nosotros" target="_blank" rel="noopener"><span>Conócenos</span><i><svg class="ico"><use href="#i-arrow"/></svg></i></a>
```

## Reglas
- Círculo `--inverse` con flecha `--on-inverse`; gira 45° al pasar el cursor.
