# ActionSquare

Cuadrado agua de 80 px (60 en móvil) con un ícono, para una acción única encastrada en una muesca del hero.

## Cuándo usarlo
- Solo dentro de una muesca (`Notch`), como pieza que la ocupa. Uno por vista.

## Markup
```html
<a class="sq" href="/contacto" aria-label="Construye con nosotros"><svg class="ico"><use href="#i-out"/></svg></a>
```
